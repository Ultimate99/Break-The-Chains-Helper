# TG:BTC Game Assistant 7.2.0 — Vision-First Daily

## Vision-first screen understanding
- Adds a dedicated **Vision Inspector** page with live screen identity, confidence, scan latency, detected safe actions and an annotated phone preview.
- Stable recorded TG:BTC screens are recognized using compact perceptual fingerprints instead of Tesseract in the navigation hot path.
- Known screen identities include Home, Mail, Shop, Quest Pass, Events, Recruit, Chain Campaign, Idle Farming popup and Rewards Obtained overlays.

## Faster safe-action recognition
- Removes the experimental full-frame multi-scale template matching that benchmarked around 0.8–1.1 seconds per frame.
- OpenCV first isolates likely action-button regions, then one compact OCR batch confirms the exact text.
- If a candidate pass finds nothing, Daily can fall back to a smaller screen-aware OCR region instead of OCRing the full 1536×709 frame.
- Same-frame analysis is cached briefly, so the second empty-screen safety verification does not OCR an unchanged frame again.

## Safety preserved
- Automation still targets only literal **CLAIM**, **CLAIM ALL** and **FREE** actions.
- BUY, EXCHANGE, USE, SWEEP, START, GO NOW and currency-spending actions never become tap targets.
- Idle Farming fixed-coordinate Claim remains allowed only after the exact Idle Farming popup is visually verified.
- Rewards Obtained overlays are dismissed only after visual overlay verification.
- Android Back is still never used to find Home.

## Navigation and reliability
- Daily route anchors now use visual screen fingerprints instead of title OCR.
- Verified Home return and retry remains active for up to four attempts.
- Fixes NumPy frame-selection expressions that could raise an ambiguous truth-value error.
- Route teaching advances from streamed frames faster instead of waiting a fixed full second between steps.
- GitHub main is only advertised as an update source when its source manifest actually exists and matches VERSION; otherwise GitHub Releases remain authoritative.

## Preserved
- Run All Safe, individual Daily modules, DRY RUN, STOP, route teaching, summaries and debug tools.
- Arena grinder, Smart Dodge, Intelligence, Strategy, History and Diagnostics.
- AppData profile, history, calibration and user settings remain untouched.
