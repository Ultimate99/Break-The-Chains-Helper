# TG:BTC Game Assistant 7.3.0 — Arena V2 + Self-Healing Daily

## Arena V2: learns from real battles
- Records continuous battle-state samples and visual events for each match.
- Persists opponent identity, username, detected heroes, power/HP perception where calibrated, threat, decisions, bot actions, duration and final outcome.
- Builds a persistent WIN/LOSS state model from your own completed battles.
- Adaptive surrender can quit a nearly-certain loss, but only after the learner has enough real WIN and LOSS examples and the loss state is confirmed across samples.

## Arena Pilot: our bot can take control
- Reuses only explicitly calibrated Strategy action points; it never invents tap coordinates.
- Starts in shadow/AUTO training mode and requires at least 12 trained matches, 4 wins, 4 losses and 2 calibrated actions before Pilot can own a battle.
- Scores actions by whether the predicted loss state improves, whether the screen actually reacts, and the final WIN/LOSS outcome.
- Automatically falls back to game AUTO after repeated no-effect actions or after the per-match safety action cap.
- Adaptive hard-loss surrender retains priority over Pilot decisions.

## Structured battle perception
- Adds persistent opponent Power and HP/team-state perception using explicit calibration rather than guessing unknown regions.
- Learned battle events are stored for later matchup/action analysis.
- Existing opponent memory, hero recognition, threat scoring and Smart Dodge remain integrated.

## Daily Assistant: self-healing Vision
- When static Vision returns UNKNOWN, page verification can use conservative title/header OCR for MAIL, SHOP, QUEST, EVENT, RECRUIT and CHAIN.
- OCR can only rescue an UNKNOWN screen; it cannot override a confidently recognized different page.
- Verified live pages can teach persistent device-specific fingerprints so the same live UI variation is recognized quickly on future runs.
- Route recovery is bounded: a failed navigation tap may retry only from verified HOME or a verified previous route page.
- Unknown screens are never navigated blindly; Android Back remains forbidden for Home recovery.
- Real route failures now save bounded diagnostic evidence in AppData for future repair.

## Safety and reliability
- Daily content taps remain restricted to literal CLAIM, CLAIM ALL and FREE actions; BUY, EXCHANGE, USE, SWEEP, START, GO NOW and spend actions remain blocked.
- Recruit FREE remains isolated from tickets/gems.
- Idle fixed claim remains available only after exact Idle popup verification.
- Existing AppData profile, history, calibration and learning files are preserved across update.
